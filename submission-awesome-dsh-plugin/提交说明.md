## 1. 条目文件

- 目标路径（放进你的 fork `Baboo-ming/awesome-dsh-plugin`）：
  `data/plugins/Baboo-ming__dsh-session-delete.yml`
- 文件名必须严格等于 `<owner>__<repo>.yml`。原来的 `Baboo-ming__dsh-my-plugin.yml` 名字不对。
- 内容即本目录下 `data/plugins/Baboo-ming__dsh-session-delete.yml`（已改好，可直接复制）。
- 一个 PR 只加这一个文件、只加这一条（规则：每 PR ≤ 3 条）。

## 2. 还差的唯一硬性项：给仓库加 `dsh-plugin` topic

插件仓库当前 `topics: []`，必须补。

网页方式（约 10 秒）：仓库页 → 右上 About 齿轮 → Topics 填 `dsh-plugin` → Save changes。

命令行方式（把 `<TOKEN>` 换成有 `public_repo` 权限的 PAT）：

```bash
curl -X PUT \
  -H "Authorization: Bearer <TOKEN>" \
  -H "Accept: application/vnd.github+json" \
  https://api.github.com/repos/Baboo-ming/dsh-session-delete/topics \
  -d '{"names":["dsh-plugin"]}'
```

注意该接口是**整体替换** topics，若要额外加 `dsh`、`deepseek-harness`，一次写全：
`{"names":["dsh-plugin","dsh","deepseek-harness"]}`
